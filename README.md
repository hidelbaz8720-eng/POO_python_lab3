# TP 3 : Héritage en Python

##  Programmation Orientée Objet (POO)

###  Objectif
Comprendre et appliquer le concept d'héritage en Python à travers deux exercices pratiques.

### Exercices réalisés

**Exercice 1 : Gestion des employés**
- Création d'une classe mère `Employe`.
- Création des classes filles `Manager` et `Developpeur`.
- Utilisation de `super()`.
- Redéfinition de la méthode `salaire_total()`.

**Exercice 2 : Bibliothèque**
- Création d'une classe mère `Document`.
- Création des classes filles `Livre` et `Magazine`.
- Redéfinition de la méthode `afficher()`.
- Gestion d'une liste de documents.
